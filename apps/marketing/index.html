Architecture

Engineered for data sovereignty.

Smart Spectator inverts the traditional cloud camera model. Your device is the host, database, and inference engine.

Device as Server

Runs an embedded HTTP and WebSocket server directly on the camera hardware. Serves live feeds and logs over local Wi-Fi without internet access.

Direct P2P Streaming

Connects viewer devices using direct LAN HTTP, WebRTC STUN peer-to-peer traversal, or optional secure relay fallback only when direct links fail.

On-Device Persistence

All configuration, session history, and event timestamps remain stored in local SQLite storage. No remote servers hold your video footage.

Hardware Conservation

Transforms capable older phones into dedicated, reliable sensors with built-in optical sensors, battery backup, and wireless connectivity.
