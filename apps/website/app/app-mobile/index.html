Your cameras

Open the dashboard from your main phone — on this phone's browser.
Enter your dashboard code
On the main phone: VYRO → Settings → Web dashboard code
  1. On the main phone open VYRO → Settings.
  2. Type the Web dashboard code here — VYRO finds the phone by itself.
  3. Your cameras open, already signed in.
This phone must be on the same Wi-Fi as the main phone. Your video never goes through the internet.
Add VYRO to your home screen: tap Share → Add to Home Screen.
