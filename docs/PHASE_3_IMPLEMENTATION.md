## 1. Executive Summary

Phase 3 transitions Smart Spectator from spatial frame-by-frame perception (Phase 2) into true **temporal event intelligence**. By consuming the continuous, structured `Observation` stream generated by Phase 2, Phase 3 establishes an end-to-end, scientifically defensible, and reproducible machine learning pipeline:

```
RAW OBSERVATION STREAM (Phase 2)
              │
              ↓
  OBSERVATION SEQUENCE CAPTURE & SLICING (30 frames @ 5 FPS)
              │
              ↓
  TEMPORAL FEATURE ENCODER (16 Object Slots + 6 Global Dynamics = 166-dim)
              │
              ↓
  FEATURE NORMALIZATION (Fitted strictly on Training Split)
              │
              ↓
  DATASET MANIFEST & SESSION SPLIT (70% Train, 15% Val, 15% Test — Zero Temporal Leakage)
              │
              ↓
  DATASET VALIDATOR (CLI Integrity & Leakage Verification)
              │
              ↓
  SPECTATORNET (BiGRU + Temporal Attention, 152k params, 0.59 MB)
              │
              ↓
  TRAINING PIPELINE (CrossEntropy + Class Weights, CosineAnnealing, Early Stopping)
              │
              ↓
  EVALUATION, ABLATIONS & ROBUSTNESS TESTS (vs. Rule-Based Baseline)
              │
              ↓
  ONNX EXPORT & NUMERICAL VALIDATION (Tolerance < 1e-4, dynamic batch)
              │
              ↓
  DYNAMIC INT8 QUANTIZATION & BENCHMARKING (0.16 ms CPU, 0.22 ms CoreML)
              │
              ↓
  PHASE 4 EVENT PREDICTION CONTRACT (Structured EventPrediction Schema)
```

## 2. Key Components Implemented

### 2.1 Event Taxonomy & Schemas (`ai/datasets/constants.py` & `ai/datasets/schema.py`)
- **Initial Target Classes:**
  1. `NORMAL_BACKGROUND`
  2. `OBJECT_PRESENT`
  3. `OBJECT_REMOVED`
  4. `OBJECT_MOVED`
  5. `PERSON_ENTERED`
  6. `PERSON_LEFT`
  7. `ZONE_LOITERING`
  8. `CAMERA_BLOCKED`
  9. `TASK_COMPLETED`
- **Schemas Defined:**
  - `TemporalAnnotation`: Versioned ground truth labels with event start/end boundaries and annotator metadata.
  - `SequenceSample`: Complete multi-frame temporal observation package.
  - `ManifestEntry`: JSONL manifest line indexing sequence samples.
  - `DatasetMetadata`: Reproducibility manifest storing dataset version, split seeds, feature dimensions, and distribution.

### 2.2 Feature Engineering & Normalization (`ai/datasets/feature_encoder.py`)
- **Structured Object Slots:** Ranks tracked objects deterministically by $(confidence \times area)$. Retains top 16 slots with zero-padding for vacant slots.
- **Slot Features (10 per object):**
  - `class_id`, `confidence`, `center_x`, `center_y`, `width`, `height`, `velocity_x`, `velocity_y`, `speed`, `normalized_area`.
- **Global Scene Features (6 features):**
  - `object_count`, `person_count`, `motion_score`, `disappeared_track_count`, `new_track_count`, `total_detections`.
- **Total Feature Dimension:** $16 \times 10 + 6 = 166$ scalar features per timestep.
- **`FeatureNormalizer`:** Fits mean and standard deviation strictly on the training partition ($z = (x - \mu)/\sigma$), preventing data leakage. Parameters serialized to `normalization.json`.
- **Ablation Modes Supported:** `presence_only`, `bbox_only`, `bbox_velocity`, and `full`.

### 2.3 Deterministic Session Splitting (`ai/datasets/split.py`)
- **Temporal Leakage Prevention:** Partitions samples grouped strictly by recording `session_id`. Overlapping temporal windows from the same session never appear in both train and validation/test splits.
- **Ratios:** 70% Train, 15% Validation, 15% Test with deterministic seed (`seed=42`).

### 2.4 Dataset Integrity Validator (`scripts/validate_dataset.py` & `ai/datasets/validator.py`)
- Standalone CLI and programmatic validator verifying:
  - Missing sequence files.
  - Duplicate sample IDs.
  - Temporal leakage across partitions.
  - Coordinate bounds ($[0.0, 1.0]$ normalization).
  - NaN or Infinite values.
  - Sequence length conformance (exactly 30 timesteps).
  - Exits with non-zero code on failure.

### 2.5 Synthetic Sequence Generator (`ai/datasets/synthetic_generator.py`)
- Generates realistic observation sequences for all 9 event classes with kinematic velocity vectors and track appearance/disappearance.
- Strictly marks `source_type="synthetic"`.
- Generated 180 samples across 10 independent sessions for CI testing and pipeline validation.

### 2.6 Rule-Based Baseline Classifier (`ai/models/baseline.py`)
- Non-neural state-machine heuristic baseline.
- Tracks transitions (person appearance/disappearance, object displacement, velocity limits, obstruction).
- Evaluated on the exact same test split for an honest scientific baseline.

### 2.7 SpectatorNet Model Architecture (`ai/models/spectatornet.py`)
- **Architecture:** Feature Projection ($166 \to 64$) $\to$ 2-layer Bidirectional GRU (hidden size 64) $\to$ Temporal Attention Pooling $\to$ Classification MLP.
- **Parameter Count:** **152,393 parameters** ($< 5\text{M}$ budget).
- **FP32 Disk Size:** **0.59 MB** ($< 15\text{MB}$ budget).
- **INT8 Disk Size:** **0.52 MB**.

### 2.8 Training Pipeline (`ai/training/trainer.py` & `ai/training/train_spectatornet.py`)
- PyTorch DataLoader with batching.
- AdamW optimizer with CosineAnnealingLR.
- CrossEntropyLoss with inverse class frequency weights.
- Early stopping monitored on validation Macro F1.
- Self-contained run logging under `artifacts/runs/<run_id>/`.

### 2.9 ONNX Export & Validation (`scripts/export_spectatornet_onnx.py` & `scripts/validate_spectatornet_onnx.py`)
- Exports model to `ai/models/spectatornet.onnx` with dynamic batch support (`['batch_size', 30, 166]`).
- Numerically validated against PyTorch:
  - **Max Absolute Error:** $2.38 \times 10^{-7}$ ($< 10^{-4}$ tolerance).
  - **Mean Absolute Error:** $5.84 \times 10^{-8}$.

### 2.10 Quantization & Hardware Benchmarks (`scripts/benchmark_spectatornet.py`)
- Dynamic INT8 quantization produces `ai/models/spectatornet_int8.onnx`.
- Measured real performance (200 iterations):
  - **CPU Latency (FP32):** **0.161 ms** (~6,179 FPS).
  - **CPU Latency (INT8):** **0.170 ms** (~5,855 FPS).
  - **CoreML GPU Latency:** **0.226 ms** (~4,413 FPS).
  - **Process Memory:** 275.4 MB.
  - **Snapdragon Hexagon NPU:** QNN Execution Provider compliant; zero simulated/fake metrics reported on macOS host.

### 2.11 Phase 4 Event Prediction Contract (`ai/models/predictor.py`)
- `SpectatorNetPredictor` executes rolling observation window inference and emits `EventPrediction` schemas matching `shared/schemas/v1/models.py`.
